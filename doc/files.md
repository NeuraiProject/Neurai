Files in the data directory (`~/.neurai` on Linux, `~/Library/Application Support/Neurai` on macOS, `%APPDATA%\Neurai` on Windows; testnet and regtest use the `testnet` and `regtest` subdirectories). Version numbers refer to the inherited Bitcoin Core history.


* banlist.dat: stores the IPs/Subnets of banned nodes
* neurai.conf: contains configuration settings for neuraid or neurai-qt
* neuraid.pid: stores the process id of neuraid while running
* blocks/blk000??.dat: block data (custom, 128 MiB per file); since 0.8.0
* blocks/rev000??.dat; block undo data (custom); since 0.8.0 (format changed since pre-0.8)
* blocks/index/*; block index (LevelDB); since 0.8.0
* chainstate/*; block chain state database (LevelDB); since 0.8.0
* assets/*; asset database (LevelDB)
* messages/*; asset message channel database (LevelDB)
* myrestricted/*; the wallet's restricted-asset tags and freezes (LevelDB)
* rewards/*; snapshot and distribution data for asset rewards (LevelDB)
* database/*: BDB database environment; only used for wallet since 0.8.0
* db.log: wallet database log file
* debug.log: contains debug information and general logging generated by neuraid or neurai-qt
* fee_estimates.dat: stores statistics used to estimate minimum transaction fees and priorities required for confirmation; since 0.10.0
* mempool.dat: dump of the mempool's transactions; since 0.14.0.
* peers.dat: peer IP address database (custom format); since 0.7.0
* wallet.dat: personal wallet (BDB) with keys and transactions
* depinstate-v2/<hash>/*: DePIN pool state for the active `-depinmsgtoken` (LevelDB): moderation hashes, and messages when `-depinpoolpersist=1`; see [depin-pool-state.md](depin-pool-state.md)
* depinpool.dat, depinpool.dat.v1.bak: message pool file of older releases; imported once into `depinstate-v2` when `-depinpoolpersist=1`, then kept with a `.v1.bak` copy
* mcp_processed.dat: messages already answered by the DePIN MCP worker (`-depinmcp`)
* .cookie: session RPC authentication cookie (written at start when cookie authentication is used, deleted on shutdown): since 0.12.0
* onion_private_key: cached Tor hidden service private key for `-listenonion`: since 0.12.0
* guisettings.ini.bak: backup of former GUI settings after `-resetguisettings` is used
