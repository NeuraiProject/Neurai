# QRKude (vendored)

Styled QR codes for the Qt wallet: receive requests, the silent payment code
card and the privacy page. Neurai only uses it through `qt/qrimage.cpp`.

- Upstream: QRKude 0.1.0, by The QRKude Authors (not yet published to a public
  repository)
- License: Apache-2.0 (see LICENSE and NOTICE)
- Files: the C99 core (`qrkude.h`, `qrk_*.c`, `qrk_internal.h`) and the Qt
  `Style`, `Code` and `Renderer` classes (`qrkude*.h`, `qrkude*.cpp`). The Qt
  widget, the Qt Quick item, tools, tests and other language ports are not
  included.
- Local changes: none
