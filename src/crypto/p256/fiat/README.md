# fiat-crypto P-256 arithmetic

Formally verified Montgomery arithmetic for the NIST P-256 field
(`p256_64.h`, `p256_32.h`) and for its group order (`p256_scalar_64.h`,
`p256_scalar_32.h`), generated by Fiat Cryptography.

- Origin: https://github.com/mit-plv/fiat-crypto, directory `fiat-c/src/`
- Commit: `3d2880ef2803faa9385589a81a835d5828eb3d38` (2026-11-12)
- Files copied unchanged; only renamed from `.c` to `.h`, because every
  function is `static` and they are included by `src/crypto/p256.cpp`.
- License: the fiat-crypto authors offer the code under MIT, Apache-2.0 or
  BSD-1-Clause; Neurai uses it under the MIT license (`LICENSE-MIT`,
  `COPYRIGHT`, `AUTHORS`).

The point arithmetic, the double scalar multiplication and the strict
NIP-060 profile live in `src/crypto/p256.cpp`; this directory only holds the
field and scalar arithmetic.
